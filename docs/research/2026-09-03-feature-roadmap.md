# 강당 모드(Auditorium Mode) 기능 로드맵 — 종합 제안

- 작성일: 2026-09-03
- 근거: [R1 경쟁 조사](2026-09-03-competitors.md) · [R2 강당 요구 조사](2026-09-03-auditorium-needs.md) · [R3 현황·기술 점검](2026-09-03-current-capabilities.md)
- 대상: 일반인·직장인 청중 수백 명 강당 강연 (의견조사 · 간단 퀴즈 · 워드클라우드 중심)

---

## 1. 전략 한 줄

> **국내 대형 강연용 실시간 참여 도구 시장은 비어 있다.** 글로벌 도구는 1,000명에 월 $49~75를 받고(R1 §1-4), 국내 도구는 전부 교실(~500명) 설계라 익명 Q&A·모더레이션·PPT 연동이 없다(R1 §4). axedu는 코드 입장·투표·퀴즈·워드클라우드·프로젝터 뷰를 이미 가졌으므로, **"익명 + 무마찰 입장 + 스케일 안정성"** 3가지를 채우면 이 자리를 차지할 수 있다.

성립 조건(R2)과 현재 코드의 거리(R3)를 잇는 것이 이 로드맵이다.

---

## 2. Phase 1 — 강당 MVP (P0 · ~200명 강연 성립)

강연자가 "다음 주 강당 강연에서 쓸 수 있다"가 목표. 참여 활동 확장이 중심.

### E1. 강당용 활동 4종 신규·확장 ⭐ 핵심 요청

| 활동 | 내용 | 근거 |
|---|---|---|
| **survey (의견조사)** | 다문항 자기 페이스 설문: 리커트 5점(1탭) + NPS 0~10 + 주관식. 표준 만족도 6문항 프리셋(만족·관련성·강사·몰입·NPS·주관식) 내장 | R2 A7-1, 표준문항 §2-축7 · R1: 설문은 전 서비스 유료 유인 기능 |
| **척도 투표(1~5)** | "적용할 수 있다고 느끼는 정도는?" 큰 버튼 5개, 분포 막대+평균 | R2 A5 타임라인 P2 슬롯 · R1: 척도는 11개 중 10개 지원 |
| **O/X · 간단 퀴즈** | 2지선다 대형 버튼, 1문항 퀵 실행(덱 편집 없이 즉석 출제) | R2 Q1 슬롯(1문항·30초) · 사용자 요청 "간단 퀴즈" |
| **Q&A 2.0** | 익명 기본 + 👍업보트 + 답변완료 체크 + 프로젝터 질문 카드(업보트 순) + 승인 후 공개 모더레이션 | R1 TOP7 1위(참여율 70% 사례) · R3 결핍 5·6 · R2 A2-7/A6-4 |

워드클라우드·롤링페이퍼·객관식 투표는 이미 있음 — E2·E3에서 익명·스케일만 보강. 활동 레지스트리 구조(활동 1종=정의 1곳, `docs/adding-activities.md`)가 이미 있어 신규 활동 추가 비용이 낮다.

### E2. 익명 시스템 (직장인 참여의 전제)

- 세션 익명 정책 4모드(익명 기본/닉네임 기본/항상 익명/항상 닉네임) + 활동 단위 오버라이드 — 퀴즈만 닉네임, 의견·자유응답·Q&A는 익명 (R2 A2-1·2)
- 프로젝터에서 익명 활동은 이름 절대 미표시 — 롤링페이퍼 닉네임 서명 제거 옵션 (R3 결핍 9)
- 결과 숨김→공개 제어(밴드왜건 방지, 기본 "마감 후 공개") (R2 A2-4)
- 참가자 화면에 "🔒 익명으로 제출됩니다" 상태 뱃지

근거: 익명일 때 피드백 의향 74%(Slido), 직장인은 상사 앞 실명 응답 회피(R2 축2).

### E3. 무마찰 입장 + 프로젝터 강당 모드

- **프로젝터 상시 입장 바**: 초대형 QR(화면 높이 10%↑) + 6자 코드 + URL + "접속 n명" 카운터, 대기 화면에선 QR 40%↑ (R2 A1-1, R3 결핍 2)
- QR 딥링크 `/join?token=` 스캔 시 닉네임 단계 직행(이미 절반 구현) + **닉네임 자동 생성**("차분한 수달 42") 1탭 입장 (R2 A1-2·3)
- 참가자 화면 "지금 할 일" 전용 모드 — 슬라이드 미러링 끄기(강당은 스크린을 본다), PDF 다운로드 비용 제거 (R3 결핍 1)
- 강당 모드 타이포: 프로젝터 텍스트 ×1.5, 선택지 4개 이하+색·도형 병기, 고대비 (R2 A4)
- 성인용 카피 톤(현재 "선생님·친구들" → 세션 유형별 문구) (R3 결핍 7)
- 활동 타이머+자동 마감(원형 게이지, 마감 시 자동 공개 옵션) (R2 A5-3, R3 결핍 12)
- 청중 화면 소리·진동·권한 요청 0 + "개인정보 수집하지 않습니다" 1줄 (R2 A8)

## 3. Phase 2 — 스케일 안정화 (P0 기술 · 400~1,000명)

강당에서 첫 활동이 실패하면 세션 전체가 죽는다(R2 축3). R3 리스크 3개를 정면 해소.

| # | 작업 | 해소하는 리스크 |
|---|---|---|
| 1 | **브로드캐스트 재설계**: 역할별 room 분리(참가자/강사·프로젝터), 참가자에겐 집계값·ACK만, 상세는 강사·프로젝터에만 200~500ms 스로틀 배치 전송 | R3 리스크1 — 워드클라우드 400명 = 1.1GB O(n²) → 수 MB |
| 2 | **rate limit**: HTTP(@fastify/rate-limit) + socket 이벤트 토큰 버킷(투표·질문), 재접속 지터+백오프 | R3 결핍 17 — 참가자 1명이 방 전체 DoS 가능 |
| 3 | **상태 영속화**: ClassroomState 주기 스냅샷(Redis 또는 Postgres)+부팅 복원, 강사 자격 계정 귀속 재접속, 참가자 점수 복원 | R3 리스크2 — 재시작=강연 종료, 강사 새로고침=강의실 유실 |
| 4 | **PDF 경로 개선**: 업로드 시 페이지별 webp 사전 렌더(이미지 슬라이드화), Cache-Control/ETag, pdf.js 자체 호스팅(사내망 CDN 차단 대응) | R3 리스크3 — 30MB×400명=12GB 스파이크 |
| 5 | **부하 테스트 CI**: k6 "30초 1,000 접속 + 10초 1,000 제출", 목표 제출 p95<2s | R2 A3-1 |

## 4. Phase 3 — 프로 강연 경험 (P1·P2 차별화)

- **폰 리모컨 모드** + **보조 진행자 역할**(활동 조작·Q&A 승인 권한 분리) + 귓속말 (R2 A6)
- **90분 강연 템플릿**: R2 §4 타임라인(워밍업 워드클라우드→2지선다→퀴즈1문항→척도→Q&A→설문→마무리 워드클라우드) 슬롯 자동 생성 + 리듬 알림("마지막 활동 후 15분") (R2 A5-1·5)
- **1페이지 PDF 리포트 자동 생성** + 공유 링크(30일)+CSV, 참여율 정의 통일, 강연자 포트폴리오(만족도 추이) (R2 A7)
- **이모지 리액션 화면 플로팅** — 11개 중 3개만 가진 차별화 기능(R1 TOP7 6위)
- 자유응답 큐레이션 뷰(진행자 픽 3~5개 크게+"외 187개"), 부적절 응답 필터 강화, 응답 60초 내 회수
- 개인정보: 보존기간 고지·세션 후 삭제 정책 — 기업 법무 검토 통과 요건 (R3 §2.5)

## 5. 수익 모델 참고 (R1 §1-4)

- 가격 앵커: 1,000명 글로벌 $49~75/월, 국내(띵커벨) 연 75,000원·500명 — **중간 지점(예: 강연 1회권 3~5만 원, 월 5~10만 원 무제한)이 비어 있음**
- 무료 경계 관행: 인원(50~100명) 또는 활성 문항 수(3~5개)로 제한, 유형은 전부 개방(전환에 유리)
- 기존 결제 인프라(토스+플랜 게이팅)에 "참가자 수" 축만 추가하면 됨 — 현재 플랜에 인원 제한 없음(R3 §1.8)

## 6. 권장 실행 순서

1. **Phase 1을 병렬 워커 4개로**: E1 활동 4종(레지스트리 덕에 병렬 적합) / E2 익명 / E3 입장·프로젝터 / 카피·타이머 — 이번 세션과 같은 오케스트레이션 패턴
2. Phase 2는 서버 구조 변경이라 **순차**(브로드캐스트 재설계 → rate limit → 영속화), 부하 테스트로 검증
3. Phase 3은 Phase 1 사용 피드백 후 우선순위 재조정
